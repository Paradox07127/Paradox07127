## 🛠 精选项目

### [Loomscreen](https://github.com/Paradox07127/macos-wallpaperengine) · 在 macOS 上运行 Wallpaper Engine 场景

![Swift](https://img.shields.io/badge/Swift-F05138?style=flat-square&logo=swift&logoColor=white)
![Metal](https://img.shields.io/badge/Metal-181717?style=flat-square&logo=apple&logoColor=white)

用 Metal 独立实现的 Wallpaper Engine 场景渲染器，同时支持多显示器视频与网页壁纸。菜单栏应用，提供播放列表、定时轮换，以及针对全屏应用、窗口遮挡和电池使用的自动播放控制。

### [Spatial-Video-Agent](https://github.com/Paradox07127/Spatial-Video-Agent) · 基于证据的视频调查

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)
![FastAPI](https://img.shields.io/badge/FastAPI-009688?style=flat-square&logo=fastapi&logoColor=white)
![Three.js](https://img.shields.io/badge/Three.js-20232A?style=flat-square&logo=threedotjs&logoColor=white)

通过自然语言问题调查多摄像头场景与行车记录仪视频，在交互式 3D 视图、地图和原始视频之间查看证据。计算机视觉与几何模块提供测量，Agent 追踪证据，并将论断标记为支持、矛盾或未确定。

### [Analyst-Copilot](https://github.com/Paradox07127/Analyst-Copilot) · 可核查的数据分析与有界 Agent

![LangGraph](https://img.shields.io/badge/LangGraph-1C3C3C?style=flat-square&logo=langgraph&logoColor=white)

![Docker](https://img.shields.io/badge/Docker-2496ED?style=flat-square&logo=docker&logoColor=white)

本地优先的分析工作台，将确定性数据画像与有界 LangGraph 工作流结合。通过证据工件、claim ledger 和校验器检查报告的引用与数值论断，模型生成的 Python 在独立 Docker 沙箱中执行。

### [claude-utopia](https://github.com/Paradox07127/claude-utopia) · 编程 Agent 开发工具

![Claude Code](https://img.shields.io/badge/Claude%20Code-D97757?style=flat-square&logo=claude&logoColor=white)
![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=flat-square&logo=typescript&logoColor=white)

一组 Claude Code 插件，提供 Agent 仪表盘与时间线、跨模型代码审查与任务委派、工作流保护，以及持久化的项目进度记录。

### [Urban-Dossier](https://github.com/Paradox07127/Urban-Dossier) · 本地纽约社区数据情报

![DuckDB](https://img.shields.io/badge/DuckDB-FFF000?style=flat-square&logo=duckdb&logoColor=black)
![vLLM](https://img.shields.io/badge/vLLM-76B900?style=flat-square&logo=nvidia&logoColor=white)
![Spark Hack NYC 2026 · Participant](https://img.shields.io/badge/Spark%20Hack%20NYC%202026%20%C2%B7%20Participant-76B900?style=flat-square&logo=nvidia&logoColor=white)

基于 DuckDB、Parquet 和 H3 构建交互式纽约地图，提供确定性社区指标、地址对比，以及由本地 Nemotron 模型生成的证据叙述。项目起源于 Spark Hack NYC 2026。
