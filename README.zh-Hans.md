### [Loomscreen](https://github.com/Paradox07127/macos-wallpaperengine) · 在 macOS 上运行 Wallpaper Engine 场景

![Metal Renderer](https://img.shields.io/badge/Metal%20Renderer-181717?style=flat-square&logo=apple&logoColor=white)
![Particle Systems](https://img.shields.io/badge/Particle%20Systems-5965D8?style=flat-square)
![Puppet Warp](https://img.shields.io/badge/Puppet%20Warp-7C3AED?style=flat-square)
![Audio-Reactive Shaders](https://img.shields.io/badge/Audio--Reactive%20Shaders-0D9488?style=flat-square)

用 Metal 独立实现的 Wallpaper Engine 场景渲染器，支持粒子系统、骨骼形变动画与音频响应着色器效果。通过每显示器渲染线程构建多屏壁纸工作台，提供视频与网页来源、播放列表和自适应播放控制。

### [Spatial-Video-Agent](https://github.com/Paradox07127/Spatial-Video-Agent) · 基于证据的视频调查

![Cosmos 3 Nano Reasoner](https://img.shields.io/badge/Cosmos%203%20Nano%20Reasoner-76B900?style=flat-square&logo=nvidia&logoColor=white)
![Cosmos Embed1](https://img.shields.io/badge/Cosmos%20Embed1-76B900?style=flat-square&logo=nvidia&logoColor=white)
![VSS / VastDB](https://img.shields.io/badge/VSS%20%2F%20VastDB-006B5E?style=flat-square)

![W&B Weave](https://img.shields.io/badge/W%26B%20Weave-FFBE00?style=flat-square&logo=weightsandbiases&logoColor=black)

使用 Cosmos 3 Nano Reasoner 理解视频、Cosmos Embed1 生成检索向量，集成 VSS/VastDB，通过 W&B Inference 调用语言模型、Weave 记录追踪。计算机视觉与几何测量为论断提供依据，在摄像头视图、3D 场景、地图与原始视频之间组织调查。**入围 Real-Time Video Hack 决赛。**
